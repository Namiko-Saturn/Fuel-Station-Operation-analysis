# Fuel-Station-Operation-analysis
 Power bi dashboard analyzing fuel station operations, sales performance and key business metrics.
### Fuel Station Operative Analysis Dashboard

Project Overview

This project presents an interactive Fuel Station Operative Analysis Dashboard developed using Power BI.

The dashboard transforms operational and sales data into clear visual insights, making it easier to monitor performance, identify trends, and understand key business metrics.

Project Objective

The objective of this project was to analyze fuel station operational data and develop an interactive dashboard that provides a clear overview of sales, revenue, costs, and profitability.

The dashboard was designed to support performance monitoring and data-driven business decision-making.

Tools Used

* Power BI
* Power Query
* Data Cleaning & Transformation
* Data Visualization

Key Areas of Analysis

The dashboard analyzes performance across several dimensions, including:

* Product
* Region
* Country
* Sales Channel
* Order Information
* Shipping Information
* Revenue
* Cost
* Profit
* Units Sold

Dashboard Features

The interactive dashboard includes:

* KPI cards for key performance indicators
* Sales and revenue analysis
* Profit and cost analysis
* Product performance analysis
* Regional and country comparisons
* Interactive filters and slicers
* Visual trends for business performance

Dashboard Preview

Key Insights

The analysis provides an overview of how sales, costs, revenue, and profitability vary across products, locations, and sales channels.

The interactive visuals allow users to explore different segments of the data and identify areas of strong or changing performance.
